Raster Operations

Local, Focal, Zonal, and Global — four operation types that cover almost everything you'll do with raster data. Explained through hop yard analysis and brewery mapping.

Operation 01

Local Operations

A local operation calculates each output cell using only the corresponding cell(s) in one or more input rasters. No neighbors, no zones, no whole-raster awareness — just cell-to-cell math at matching positions.

Think of it as a spreadsheet formula applied to every cell simultaneously. If you multiply cell (3,4) in raster A by cell (3,4) in raster B, that's local. Every cell is calculated independently from its matching position.

🍺 Hop Yard Example
You have two rasters covering your hop yard — soil nitrogen levels and moisture content. You multiply them together to produce a hop growth potential surface. Each cell's output uses only the nitrogen value and moisture value at that same location. No neighbors involved — just cell × cell.

Exam Trigger
"Multiply raster A by raster B" · "Add two rasters" · "Subtract" · "Reclassify values" · "Change detection (raster A minus raster B)" → all Local. No neighbors, no zones = Local.
Operation 02

Focal Operations

A focal operation calculates each output cell using a neighborhood of surrounding cells — a moving window that sweeps across the raster. The output at each cell depends on what's around it, not just the cell itself.

Common window sizes are 3×3 (the cell plus its 8 neighbors) or 5×5 (the cell plus its 24 neighbors). Slope and aspect calculation from a DEM are classic focal operations because they need to know the elevation of surrounding cells to calculate the rate of change.

🍺 Hop Yard Example
Your hop yard elevation raster has noisy measurements from the survey. You apply a 3×3 smoothing filter — replacing each cell with the average of itself and its 8 surrounding neighbors. The resulting surface is smoother, making it easier to plan irrigation channels along gentle slopes. Each output cell looks at its neighborhood.
Focal examples

• Slope calculation from DEM
• Aspect (slope direction)
• 3×3 or 5×5 smoothing filter
• Majority filter (most common value in neighborhood)
• Any operation with a window size

The 3×3 window

Each center cell's output is calculated from itself + 8 surrounding cells. The window moves across the entire raster, one cell at a time. Output at edges may be NoData where the window extends beyond the raster boundary.

Exam Trigger
"Surrounding cells" · "Neighboring cells" · "Moving window" · "3×3 filter" · "Slope from DEM" · "Aspect" · "Smoothing filter" → all Focal. If neighbors are involved = Focal.
Operation 03

Zonal Operations

A zonal operation calculates statistics for groups of cells that share the same zone value. The zones are defined by a second raster or a polygon layer — and the statistic (mean, max, sum, min) is calculated for all cells within each zone.

The output is one value per zone — not one value per cell. This is the operation for questions like "what is the average elevation within each watershed?" or "what is the maximum temperature in each climate zone?"

🍺 Hop Yard Example
Your hop yard has four varieties planted in different zones — Cascade, Centennial, Citra, and Mosaic. You want to know the average soil moisture within each hop variety zone. The hop variety polygons define the zones. The moisture raster provides the values. Zonal statistics returns one average per variety zone.
Exam Trigger
"Per polygon" · "Per watershed" · "Within each county" · "Per climate zone" · "Per school district" → all Zonal. The phrase "within each ___" where the blank is a zone or polygon = Zonal every time.
Operation 04

Global Operations

A global operation uses all cells in the entire raster to calculate each output cell. Every cell in the dataset participates in every calculation. These operations have whole-raster awareness.

The most common global operation is Euclidean distance — how far is each cell from the nearest feature? To answer this, the algorithm must consider the entire raster to find the nearest feature for every single cell.

🍺 Brewery Example
You want to know how far each point in Washington State is from the nearest craft brewery. The Euclidean distance tool calculates the distance from every single cell to the nearest brewery point — scanning the entire raster for each cell. That whole-raster awareness = Global.
Exam Trigger
"Euclidean distance" · "Cost distance" · "Viewshed" · "Distance from every cell to nearest feature" → all Global. Distance and visibility calculations that need whole-raster context = Global.
