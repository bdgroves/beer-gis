Overlay Operations

Union, Intersect, Clip, and Erase — finding the perfect taproom location using zoning layers, school buffers, and neighborhood boundaries.

🍺 The Scenario

You're a GIS consultant helping a client site a new craft brewery taproom in Seattle. You have four spatial layers: zoning districts, neighborhood boundaries, school locations, and available parcels. Each overlay operation answers a different question about where the taproom can go.

Operation 01

Union

Union combines all features from both input layers into a single output. The full geographic extent of both inputs is preserved. Attributes from both layers are included in every output feature.

Think of Union as adding two datasets together — you get everything from A, everything from B, and where they overlap you get features with attributes from both.

🍺 Taproom Example
You want a single map layer showing both zoning districts AND neighborhood boundaries for the whole city. Union gives you the complete picture — every parcel now has both its zoning classification and its neighborhood name. No data is discarded.
Exam Trigger
"All features from both" · "Combine two layers" · "Full extent of both" · "Merge" → Union
Operation 02

Intersect

Intersect returns only the areas where both input layers spatially overlap. Anything outside the overlap is discarded. Attributes from both layers are preserved in the output — but only for the overlapping areas.

The AND condition: a feature must satisfy both inputs simultaneously to appear in the output. This makes Intersect the go-to operation for "within" and "inside" queries.

🍺 Taproom Example
Your client wants parcels that are zoned commercial AND located within the Ballard neighborhood. Intersect returns only the parcels where both conditions are spatially true — commercial zoning overlapping the Ballard boundary. Everything else is discarded.
Exam Trigger
"Within" · "Inside" · "Overlap" · "AND condition — both must be true" → Intersect
Operation 03

Clip

Clip uses one layer as a cookie cutter on another. The output has the shape of the clip boundary, containing only the features from the input layer — with only the input layer's attributes. The clip layer is just the cutting shape, its attributes are not transferred.

🍺 Taproom Example
You have a statewide roads layer but only need streets within King County for your delivery route planning. Clip uses the King County boundary as the cookie cutter — roads are cut to that shape, only the roads layer's attributes remain.
Exam Trigger
"Cut to the boundary of" · "Extract features within study area" · "Cookie cutter" → Clip
Operation 04

Erase

Erase removes the area of one layer from another. The output is the first layer (A) with the second layer's (B) area punched out of it. Use Erase when you want what is OUTSIDE a zone.

🍺 Taproom Example
Washington State liquor licensing requires taprooms to be more than 500 feet from schools. Buffer all schools by 500 feet, then Erase that buffer from the available parcels layer. What remains are parcels that are safely outside the school exclusion zones.
⚠️ The Direction Rule — Never Miss This
Want what's INSIDE a zone → Buffer → INTERSECT
Want what's OUTSIDE a zone → Buffer → ERASE

"Taprooms within 1 mile of downtown" → Buffer + Intersect
"Taprooms more than 500ft from schools" → Buffer + Erase
Exam Trigger
"Outside" · "Beyond" · "More than X distance away" · "Exclude" · "Remove" → Erase
