Classification Methods

Natural Breaks, Quantile, Equal Interval, and Standard Deviation — mapping brewery ratings across Washington State to understand which method reveals which patterns.

🍺 The Dataset

You have Untappd ratings for 400 Washington State craft breweries, ranging from 3.2 to 4.9. The distribution is right-skewed — most breweries cluster between 3.8–4.3, with a handful of exceptional breweries scoring 4.7–4.9. The classification method you choose will dramatically change what the map communicates.

Method 01

Natural Breaks (Jenks)

Natural Breaks places class boundaries where the data has its largest jumps — minimizing differences within classes and maximizing differences between classes. The algorithm (Jenks optimization) finds the natural clusters in the data distribution.

It adapts to the actual data, which makes it excellent for revealing real patterns in unevenly distributed or skewed datasets.

🍺 Brewery Rating Example
With our right-skewed brewery rating data, Natural Breaks finds the real gap between the large cluster of good breweries (3.8–4.3) and the handful of exceptional ones (4.7–4.9). The class boundary falls exactly where the data jumps — cleanly separating the exceptional breweries from the rest.
⚠️ Key Weakness
Natural Breaks recalculates from each dataset independently. If you make a map of brewery ratings in 2023 and another in 2024, the class breaks will be different — making direct year-over-year comparison meaningless. Never use Natural Breaks for a map series.
Exam Triggers
"Natural gaps in data" · "Natural clusters" · "Skewed data" · "Outliers" · "Show true magnitude differences" · "Best represents the distribution" → Natural Breaks
Method 02

Quantile

Quantile puts exactly the same number of features in each class by adjusting the class break values to accommodate the data distribution. With 400 breweries and 5 classes, each class gets exactly 80 breweries.

The result is a visually balanced map — no class appears empty or overloaded. But this visual balance comes at the cost of statistical accuracy.

🍺 Brewery Rating Example
Quantile forces 80 breweries into each class regardless of their actual rating spread. A brewery rated 4.2 might end up in the same "high" class as one rated 4.9, just to balance the count. The map looks visually balanced but makes the 4.2 and 4.9 breweries appear equivalent — misleading for anyone trying to find the truly exceptional ones.
⚠️ Key Weakness — Most Misleading for True Differences
Quantile groups unlike values together to balance counts. It's the most misleading method when the goal is showing true magnitude differences between features. A brewery rated 3.9 and one rated 4.8 could end up the same color.
Exam Triggers
"Same number of features per class" · "Equal number of breweries in each class" · "Visually balanced map" · "Relative rank" → Quantile
Method 03

Equal Interval

Equal Interval divides the data range into classes of equal width. With ratings from 3.2 to 4.9 and 5 classes, each class covers exactly 0.34 rating points: 3.2–3.54, 3.54–3.88, and so on.

It works well when data is uniformly distributed. With skewed data it creates empty classes — most breweries pile into a couple of classes while others sit empty.

🍺 Brewery Rating Series Example
You're mapping average brewery ratings per county for 2020, 2021, 2022, and 2023. You need viewers to compare maps year over year — so dark amber must mean the same rating range on all four maps. Equal Interval with fixed predetermined breaks is the only method that guarantees this consistency. Set the breaks once, apply to all four maps.
Exam Triggers
"Map series" · "Year-over-year comparison" · "Same class breaks across maps" · "Uniform distribution" → Equal Interval (fixed breaks)
Method 04

Standard Deviation

Standard Deviation groups features by how many standard deviations they fall above or below the mean. Class breaks are set at intervals of ½ or 1 standard deviation from the mean — making it immediately clear which features perform significantly above or below average.

Works best with normally distributed data. Pair with a diverging color scheme for maximum visual impact.

🍺 Brewery Rating Example
The state average brewery rating is 4.1. Using Standard Deviation classification, you can immediately see which counties have breweries performing more than one standard deviation above average (exceptional brewing regions) or below average (underperforming areas). Pair with a diverging color scheme: deep amber for above average, neutral for average, grey for below.
Exam Triggers
"Above/below average" · "Deviation from mean" · "More than one standard deviation" · "Normally distributed" → Standard Deviation + Diverging color scheme
