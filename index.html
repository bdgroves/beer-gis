About this project

Built as a study companion for the GISP certification exam — GIS concepts explained through craft beer scenarios from the Pacific Northwest. Every method and principle here maps directly to real exam content.

Data sources

Brewery data from OpenStreetMap and the Brewers Association. Hop growing region data from USDA. Washington State administrative boundaries from the Census Bureau. All analysis performed in Python with GeoPandas and Folium.
