🎨 Cartographic Design · GIS Concepts

Bertin's Visual Variables

Value, Hue, Size, Shape, Texture, and Orientation — building a Pacific Northwest beer tourism map that communicates multiple data dimensions simultaneously.

🍺 The Map

You're designing a Pacific Northwest craft brewery tourism map. You need to communicate brewery type, rating, production volume, trail status, and delivery route direction — all on a single map. Each piece of information needs its own visual variable.

Variable 01

Value (Lightness)

Value describes the lightness or darkness of a symbol — from light to dark within a single hue family. The eye naturally reads darker as "more" or "higher ranked," making value the most effective variable for ordered or quantitative data.

🍺 Brewery Map Example
Brewery symbols shaded from light gold (lower Untappd rating) to dark brown (higher rating). All the same hue — just getting progressively darker. A reader immediately understands: darker = better rated.
3.5 rating 4.0 rating 4.5 rating 4.9 rating
⚠️ Value vs Hue — The Most Common Mistake
Value = same color getting lighter or darker (light amber → dark amber)
Hue = different colors (amber → blue → green)
Yellow → red is a HUE change, not value. Light yellow → dark yellow is a VALUE change.
Use for
Ordered / quantitative data · "more vs less" · continuous gradations
Variable 02

Hue

Hue is what we commonly call "color" — red, blue, green, orange, etc. Because different hues don't naturally imply a ranking or quantity, hue is most effective for nominal (categorical) data where categories are just different, not more or less of something.

🍺 Brewery Map Example
Red symbols for IPA-focused breweries, blue for stout-focused, green for lager-focused, orange for sour-focused. No implied ranking between beer styles — they're just categorically different.
IPA Stout Lager Sour
Use for
Nominal / categorical data · types · classes with no implied order
Variable 03

Size

Size encodes quantity through the physical dimensions of a symbol — larger means more. At point locations this creates graduated or proportional symbol maps. Size also applies to line weight (thicker lines = more significant).

🍺 Brewery Map Example
Larger circles for breweries with higher annual barrel production. Fremont Brewing's large circle immediately communicates it's a major regional producer. Your neighborhood nano-brewery gets a small circle.
500 bbl 5,000 bbl 25,000 bbl 100,000 bbl
Use for
Quantitative data at point locations · raw counts · line weight for hierarchy
Variable 04

Shape

Shape encodes nominal differences through different symbol forms — circle, square, triangle, star, etc. Like hue, shape doesn't imply quantity or ranking, making it appropriate for categorical data at point locations.

🍺 Brewery Map Example
Circle symbols for production breweries, square symbols for brewpubs, triangle symbols for taproom-only locations. All the same size and color — just different shapes to distinguish venue type.
Use for
Nominal categories at point locations · feature types · distinguishing things that are different but not ranked
Variable 05

Texture

Texture describes the arrangement, spacing, and pattern of visual marks — dashed vs. solid lines, fine vs. coarse hatching, stippled vs. smooth fills. It's the structure of the visual pattern, not its lightness or color.

🍺 Brewery Map Example
Solid lines for year-round open breweries. Dashed lines for seasonal-only breweries. Stippled fill for historic/closed brewery locations. The pattern of marks changes, not the color or size.
⚠️ Texture vs Value
If it's a dashed/dotted/hatched PATTERN → Texture
If it's the same color getting lighter or darker → Value
Stipple, hatch spacing, solid vs dashed = always Texture.
Use for
Nominal or ordered distinctions using patterns · dashed vs solid · hatch density
Variable 06

Orientation

Orientation encodes information through the angle or direction of a symbol. It's specifically suited for directional data — wind direction, migration routes, flow direction, slope aspect.

🍺 Brewery Map Example
Arrows on the brewery map showing delivery truck route directions. The angle of each arrow encodes which direction trucks travel from each brewery. Often combined with Size (arrow length = delivery volume) to encode two variables simultaneously.
Use for
Directional data · wind direction · current/flow direction · migration routes
